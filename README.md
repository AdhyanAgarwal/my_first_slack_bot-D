This is a simple slack bot made by Adhyan Agarwal. 

it responds to 9 different slash commands :)

The commands are:   

/the-bot-ping 

/the-bot-catfact  

/the-bot-joke  

/the-bot-dog

/the-bot-advice

/the-bot-uselessfact

/the-bot-activity

/the-bot-dadjoke

/the-bot-help  

ping helps to get the latency of the bot  

joke command tells the user a joke  

catfact command tells the user a catfact  

dog command gives the user a random dog image

advice command gives the user a random piece of advice

uselessfact command gives the user a random useless fact

activity command gives the user a random activity idea

dadjoke command gives the user a random dad joke

help command gives the user a list of available commands  

 It runs 24/7

demo link: https://hackclub.enterprise.slack.com/archives/C0C19Q7SP53
